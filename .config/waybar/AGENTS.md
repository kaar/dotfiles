## AirPods Helper

- `airpods.sh` is the sole implementation for the `custom/airpods` Waybar module. Keep both `status` and `connect` behavior in this file rather than creating a second A2DP helper.
- `status` must emit one compact JSON object with `text`, `tooltip`, and `class`; supported classes are `connected`, `audio-connected`, `disconnected`, and `unavailable`. Preserve `connected` alongside `audio-connected` so existing Waybar styling continues to apply.
- `connect` resolves the existing trusted Caspar AirPods by name. Never store or document their Bluetooth address.
- Treat connection as a no-op only when BlueZ reports connected and the PulseAudio A2DP sink is present and already selected as the default. Otherwise request the A2DP Audio Sink UUID, select `a2dp_sink`, set the default sink, and move active playback streams.
- Do not pair, remove, untrust, reset, or play test audio unless explicitly requested. [`AIRPODS_FIX.md`](./AIRPODS_FIX.md) is the one-time recovery procedure for an invalid bond; [`README.md`](./README.md) documents normal use.
